# Существующая структура, 2026-10-06

- TypeScript, Obsidian API 1.13.1 в установленной dev-зависимости, esbuild, Vitest.
- src/main.ts: плагин, настройки и регистрация вкладки. src/scan.ts: дерево файлов и кэш подсчёта слов по mtime.
- src/view.ts: sunburst, три метрики, обновление при изменении файлов и настроек.
- Чистые расчёты, геометрия и 13 локализаций находятся в отдельных модулях src.
- tests/pure.test.ts содержит 27 существующих тестов. npm test запускает Vitest; npm run lint проверяет src; npm run build запускает TypeScript и production-сборку в main.js.
- manifest.json сохраняет minAppVersion 1.8.7, зависимости в этой задаче не обновляются.
- .plan.md является существующим планом; подключён локальный Spec Kit CLI 1.0.5 для следующих изменений.
- Дерево Git до начала разработки было чистым. Реальное хранилище и настройки пользователя не изменяются.
