# Принципы Vault Sunburst

Версия 1.0.0, 2026-10-06. Источник: существующая структура и запрос владельца.

- Анализ остаётся локальным и не изменяет файлы хранилища.
- Сохраняются диаграмма, три метрики, исключения, локализация и минимальная версия Obsidian.
- Ошибки чтения не блокируют повторный подсчёт слов.
- Новые API настроек используются с сохранением старой вкладки настроек.
- Исправления имеют воспроизводимую регрессионную проверку; обязательны npm test, npm run lint и npm run build.
- Следующие изменения описываются в specs через спецификацию, план и задачи. Существующий код не переписывается ради подключения Spec Kit.
- Личные каталоги !notes исключены из Git через паттерн \!notes/. Установка в настоящее хранилище и публикация выполняются только по отдельному разрешённому запросу.

Текущие указания пользователя имеют приоритет над этим документом.
